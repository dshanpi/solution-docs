# 课程学习导航

`catalog.js` 是课程界面的章节数据源。课程首页、桌面与手机目录、阶段路线和上下章导航共用它。新增或调整课程时，同时核对 `docs/course` 的 frontmatter、分类元数据和此文件中的标题、短标题、顺序与路径。

主题包装组件为课程文档自动加入导航，正文继续使用 Markdown，无需逐章插入 JSX。基础 24 章及 4 个进阶专题计入完成进度；项目介绍和系统框架不计入。

`ProgressProvider` 保存浏览记录、最后访问章节和手动完成标记。仅打开页面不会自动完成。数据保存在当前站点、当前浏览器的 localStorage 中，不跨设备同步。存储不可用时保留本次会话状态，并显示提示。损坏记录与已删除的章节路径会被过滤。

验证：

```sh
node --test tests/learning-progress.test.mjs
npm run build
```

浏览器检查：点击章节、阶段切换、标记与撤销完成、刷新恢复、首页继续学习、手机菜单及深色主题。
