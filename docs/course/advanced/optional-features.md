# 方案功能与扩展接口

配套方案聚焦**视频、键鼠、终端和基础设置**。评估扩展时，先确定要增加哪条数据或控制路径，再检查它是否影响现有视频与输入。

## 当前交付功能

| 功能 | 使用入口 | 验证结果 |
| --- | --- | --- |
| 视频 | 浏览器视频区域 | 固定 1080p60 链路通过短时上机验证 |
| 键鼠 | 键盘、绝对/相对鼠标、滚轮 | 由 USB HID 服务完成，按主机和场景验收 |
| 终端 | 浏览器终端面板 | 访问 KVM 系统的 Shell，不是被控主机终端 |
| 基础设置 | 设置面板 | 访问认证、界面与连接维护等现有选项 |

当前配套界面与业务不提供音频、MTP、虚拟介质、VPN、OTA、ATX 电源和 Wake-on-LAN。不能将其他产品的界面功能当成本方案已有能力。

## 增加功能时选择哪个接口

| 需求 | 需要适配的位置 | 必须验证的影响 |
| --- | --- | --- |
| 更换采集硬件 | 驱动、视频后端与平台配置 | 输出格式、时间戳、重连、画质与帧率 |
| 增加动态分辨率 | 输入检测、缓冲区、编码器和网络协商 | 格式切换期间的资源释放与恢复 |
| 扩展 USB 功能 | HID 服务之外的设备管理设计 | UDC、端点、枚举及现有键鼠连续性 |
| 新增系统操作 | 平台服务能力、配置与授权 | 可访问设备范围、失败与断线恢复 |

KVM2 当前传输 H.264，不能直接在 payload 后追加音频或任意数据。**扩展应定义独立媒体通道或明确的新协议，同时更新消费端**。

## 验收扩展后的整套方案

扩展不只需要证明新增功能可用，还要重跑视频、输入释放、终端、会话切换和冷启动检查。例如**重新绑定 UDC 会影响同一 Gadget 内的键鼠**，不能只观察新 USB 功能是否出现。

对外功能清单应写明硬件组合、软件版本、运行条件和恢复方法。本指南提供当前系统的开发与应用路径；新的能力应在实际实现并通过验证后再加入清单。
