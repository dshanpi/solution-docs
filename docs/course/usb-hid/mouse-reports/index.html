编写相对鼠标和绝对鼠标程序

远程操作既需要“向右移动一点”，也需要“指向画面的某个位置”。前者适合相对鼠标，后者适合绝对鼠标；两者不能共用同一种字节布局。

相对鼠标：发送位移​

kvm-hid-service/c/descriptors.h 中的相对鼠标描述符定义 4 字节、无 Report ID 的报告：

字节含义当前范围
0八个按钮的位图每 bit 一个按钮
1X 相对位移-127 到 127
2Y 相对位移-127 到 127
3滚轮-127 到 127

例如 00 0A 00 00 表示无按钮按下、X 方向移动 10；00 F6 00 00 表示 -10 的补码表示。主机的加速度设置可能改变最终屏幕像素位移，所以 +10 不必等于屏幕上正好 10 像素。

当前 gadget.c 的 relative 操作把第四字节置 0；滚轮通过独立 wheel 操作发送到绝对鼠标功能的 Report ID 2。报告描述符和服务操作必须一起阅读。

绝对鼠标：发送坐标​

绝对鼠标描述符的 Report ID 1 用于绝对位置，坐标范围 0—32767：

byte 0   byte 1   byte 2  byte 3   byte 4  byte 5
ID=1     buttons  X low   X high   Y low   Y high

图 1：绝对位置报告。

X、Y 都按低字节在前发送，不能直接复制与主机字节序绑定的 C 结构体。

若内容区域坐标范围是 0 到 W-1，可将 x 缩放为 x * 32767 / (W - 1)，Y 同理。运算前裁剪到内容区域，处理 W/H≤1，使用足够宽的中间整数避免溢出。

// x、y 已换算并裁剪到 0..32767；buttons 只使用描述符声明的按钮位。
unsigned char report[6] = {
    1, buttons,
    x & 0xff, (x >> 8) & 0xff,
    y & 0xff, (y >> 8) & 0xff
};

这是报告构造片段，写入和错误处理应沿用键盘实验的完整报告原则，并改为匹配的长度和设备节点。

滚轮使用另一份 Report ID​

当前绝对鼠标描述符的 Report ID 2 用于相对滚轮，发送 02 wheel 两字节；配置的 report_length=6 是该功能最大输入报告长度，不意味着每个 Report ID 都必须拼成同样六字节。

功能项目设备节点报告长度
绝对位置hidg16，含 ID 1
绝对鼠标功能中的滚轮hidg12，含 ID 2
相对位置hidg24，无 ID

画面缩放后的坐标​

网页可能为保持长宽比留黑边。鼠标坐标应相对实际视频内容区域计算，而不是相对整个页面或包含黑边的容器。浏览器缩放、全屏、视频旋转和动态分辨率都会改变映射条件。

鼠标输入的验收

验收至少覆盖四角、中心、拖动、释放按钮、滚轮，以及退出控制后的全按钮释放。鼠标移动正常但点击位置偏移时，优先区分报告布局与网页内容区域映射，不先修改 USB 驱动。
